# 03 — Tag-triggered release pipeline

Status: done
Blocked by: 01

Implements spec §3.9: replace the dispatch-only build with a deterministic release pipeline.

## Scope

- `.github/workflows/release.yml` (new)
- `.github/workflows/python-app.yml` (deleted — superseded)

## Steps

1. Trigger on `push` of tags `v*`; `permissions: contents: write`.
2. Build matrix (ubuntu-latest, windows-latest):
   - `actions/checkout`, `astral-sh/setup-uv`, `uv python install 3.13`, `uv sync --frozen`.
   - Generate `src/llm_proof/_version.py` from `${GITHUB_REF_NAME#v}`.
   - `uv run --with pyinstaller==6.20.0 pyinstaller --onefile --name llm-proof src/llm_proof/main.py` (Windows: backslash path).
   - Upload `dist/llm-proof` (Linux) / `dist/llm-proof.exe` (Windows) as an artifact named `llm-proof-{os}-x64`.
3. Release job (needs build): download artifacts, rename the files to `llm-proof-linux-x64` / `llm-proof-windows-x64`, publish with `softprops/action-gh-release@v2` (not draft, not prerelease, no autogenerated notes).
4. Delete `python-app.yml`.

## Done when

- Pushing `v0.3.0` produces a GitHub release with exactly the assets `llm-proof-linux-x64` and `llm-proof-windows-x64`, each a bare executable carrying `__version__ = "0.3.0"`.
